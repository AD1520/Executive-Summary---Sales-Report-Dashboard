# Executive Summary - Sales Report

A Power BI dashboard tracking global sales trends, product categories, and regional order distributions across fiscal years (FY2018–FY2021).

## Key Features & Visualizations

* **Sales Trends Analysis (Line Chart):** Compares monthly `Sales Amount` against `Sales Amount by Due Date` to analyze revenue recognition timing and seasonal peaks across months (January–December).
* **Geographic Order Distribution (Map Visual):** Displays `Sum of Order Quantity by Country-Region`, highlighting demand hotspots across North America, Europe, and Australia.
* **Product & Channel Performance Matrix:** Detailed revenue matrix categorizing sales performance by:
  * **Business Types:** Warehouse, Value Added Reseller, Specialty Bike Shop, and Direct sales.
  * **Product Categories:** Accessories, Bikes, Clothing, and Components.
* **Fiscal Year & Month Slicers:** Dynamic filtering capabilities covering fiscal years `FY2018`, `FY2019`, `FY2020`, and `FY2021`.

## Tools Used
* **BI Tool:** Microsoft Power BI Desktop
* **Data Visualizations:** Dual-axis Area/Line Chart, Map, Matrix Table, Slicer controls
